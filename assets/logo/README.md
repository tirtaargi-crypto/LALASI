# LALASI logo assets

- `lalasi-logo.png` — official white mark on transparent canvas.
- `lalasi-logo-transparent.png` — transparent white mark export for overlays.
- `lalasi-logo-dark.png` — dark monochrome mark for light surfaces.
- `lalasi-icon.png` — dark repository/avatar icon.

The artwork is derived from the official logo already present at
`app/src/main/res/drawable-nodpi/lalasi_official_logo.png`. These repository
exports do not replace Android launcher or splash assets.
