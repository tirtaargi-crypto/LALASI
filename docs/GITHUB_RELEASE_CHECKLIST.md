# GitHub repository publishing checklist

This source archive cannot change repository settings on GitHub. Apply the following metadata after creating or opening the repository.

## Suggested repository description

LALASI — A modern music experience with premium Liquid Glass design, immersive visuals, seamless navigation, and a beautifully crafted listening experience.

Use this description only after confirming it accurately represents the published revision.

## Suggested topics

`lalasi` `music-player` `android` `kotlin` `jetpack-compose` `liquid-glass` `music-streaming`

Remove any topic that does not match the final public source or enabled functionality.

## Repository presentation

- Upload `assets/logo/lalasi-icon.png` as the repository avatar.
- Set `assets/social/lalasi-social-preview.png` as the social preview image.
- Use `assets/banner/lalasi-banner.png` in the README hero.
- Add only real screenshots captured from a running application to `assets/screenshots/`.
- Set a website URL only if an official, working project website exists.
- Add the verified developer GitHub profile URL to the README. No profile URL was inferred or fabricated.

## Before public release

- Review the retained `LICENSE` and third-party attribution obligations.
- Check provider/API terms and remove private credentials from the repository.
- Verify README claims against the exact release commit.
- Add release notes and tags only after a release has actually been created.
